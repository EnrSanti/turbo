2. Shape of the kernel

while(true) {                                   // round loop  l.912
  while(idx < num_subproblems && !stop) {        // B (unchanged)
    C : round 0 ? copy global root              // l.932
        : C' rebuild item idx >> s_bits         // l.941  (§4)
    D : dive s_bits bits    E : skip (fetch_max)
    F : DFS; if(restart){ open_subproblem=!stop; break; } // l.1225
    G : idx = next_subproblem++                 // l.1251
  }
  if(!restart_enabled) break;                   // old behaviour
  if(!stop && !restart) idle_blocks++;          // ran out of work
  grid.sync();  ++round;                        // S1   l.1278
  if(open_subproblem) harvest();                // dump stack (§3)
  if(block 0, thread 0) reset_round();          // in parallel
  grid.sync();                                  // S3   l.1368
  n = n_items[round&1]; if(host_stop||n==0) break;
  s = min s: n·2^s >= T (T=30·B); num_subproblems = n<<s;
  idx = blockIdx.x;                             // next round
}

Trigger (propagate, l.1610–1630): in thread 0, once per node, a busy block checks idle_blocks ≥ ⌈P·B/100⌉ and round ≥ restart_min_ms. The winner of a CAS on restart_flag raises it, and every busy block sets its shared restart. The check is done by busy blocks, not idle ones, because an idle block is already waiting in S1 and would never check again.

Where a block stops: at the end of the DFS body. The last split or backtrack has embedded the next node but not propagated it, so the current node is unexplored and nothing is lost or done twice. Dives (D) and rebuilds (C′) are never interrupted, so at S1 no block is in the middle of one.

3. Dumping the stack (harvest, after S1, l.1283–1339)

When a block stops, its open work is fully described by root_store (the subproblem root after the dive) plus the decision stack decisions[0..depth). Each entry has var, children[0/1] (L / R = ¬L) and current_idx (the child it is in).

Prop. 1 (frontier): the unexplored part is exactly the disjoint union of:

  • Rk for every level with current_idx = 0 (the right branch was never started);
  • the current node (the top level, child current_idx).

Levels with current_idx = 1 are finished: their left subtree is refuted, and those are Lecoutre's nld-nogoods. They are simply left out, so no nogood needs to be stored.

  1. Snapshot (all threads): root_store → snap_store and decisions[i] → snap_dec[i] (var, children, ropes, current_idx, strided). Thread 0 also saves snap_depth, the root strategy and the next unassigned variable. snap_dec is resized first if decisions has grown.
  2. Items (thread 0): count pending = #levels with ci = 0, reserve m = pending+1 slots with one n_items[round&1].fetch_add(m), then write {snap=blockIdx, k, c=1} for each pending level (shallowest first), plus {blockIdx, depth−1, ci} for the current node.

FrontierItem {int snap; k:31; c:1} = 8 B, l.100. An item is a reference, not a copy: "the path of block snap down to level k, then child c". Paths of any depth stay in the snapshot, so all items have the same fixed size. The quota is 1024 items per block; if a block exceeds it, the deeper levels are merged into one bigger item (counted in restart_truncated_blocks; never seen so far).

Memory: allocated once (allocate_snapshot, l.215/859, only with -restart): one store, one stack and 1024 item slots per block (l.736).

4. Reusing it (rebuild C′, next round, l.941–969)

item = items[idx >> s_bits];  src = blocks[item.snap];
src.snap_store->copy_to(store);                 // its root store
repeat until no change:                          // all threads
  for i < k: store.embed(snap_dec[i].var, snap_dec[i].current());
store.embed(snap_dec[k].var, snap_dec[k].children[c]);
strategy, next_var = src.snap_root_*;  depth = 0;

This is exactly the barebones backtrack (step IV), except that it reads another block's snapshot. No propagation is done here: the first propagate() of the dive computes the fixpoint. Then the block runs D/E/F as in round 0, using the low s_bits of idx as the dive path.

Why paths never accumulate: after a rebuild, the whole prefix is inside the new root_store and the stack restarts at depth 0. At the next restart the block snapshots that store plus a short stack. One snapshot buffer per block is enough: it is written only between S1 and S3 and read only during a round.

Split: with n items, s = the smallest value with n·2s ≥ T = 30·B. Index j maps to item j >> s, and the low s bits of j are the dive bits. Prop. 2: 2rd divides 2s, so the E skip never crosses into another item, and D/E stay unchanged. Round 0 = one ROOT item, s = subproblems_power (bit-for-bit the old EPS).

5. Why the synchronisation is needed

grid.sync() is a barrier for every thread of every block, and also a device-wide memory fence. It requires cudaLaunchCooperativeKernel (l.632) with all B blocks resident at once: the occupancy is rechecked and B reduced if needed (l.786). A block that is not running could never arrive, and everyone would hang.

barrierguaranteeswithout it
S1
freeze		no block is still exploring: every stack, root_store and best_bound is final, and nobody reads the counter, the flag or the snapshots any morea block would snapshot a stack that is still changing (lost or duplicated nodes), and the reset would clear the counter or flag while busy blocks still use them
S3
publish		all items and n_items are written, and the reset (bound, counter, flags, host_stop) is visible to every blocka block would read a partial n, or items not yet written, and blocks would compute different n or s, so subproblems would be lost or repeated

One-writer rule (why harvest and reset can run in parallel between S1 and S3): in that window each datum is either written or read, never both, and it has a single writer or is updated atomically.

  • Harvest writes its own snap_* and its own item range; the shared counter only via fetch_add.
  • Block 0 alone writes:
    • (1) the exact bound, the min over the frozen best_bounds (this repairs the racy meet);
    • (2) host_stop, read once;
    • (3) next_subproblem = B;
    • (4–6) idle_blocks, restart_flag and round_start set to 0 or now;
    • (7) n_items[(round+1)&1] = 0. Two counters alternate, because the current one is still being filled.
No deadlock: the decision to leave the loop must be identical in every block. If one block breaks while another enters grid.sync(), the GPU hangs. So the exit is decided only on values written before S3 and read after it (host_stop, n), never on the per-block stop. A node limit also sets the global stop (l.1605). There is no return inside the loop, and idle blocks wait only in grid.sync(). S2 (for a global sort or per-item depths) was dropped; it can be added later.

No !restart in the loop condition: idle ⇒ the counter is exhausted, so after a restart break step G hands out an index ≥ total and the block leaves the loop by itself.

6. Other changes

  • Bug fix, step E (l.1067): while(next.meet(t)) is load/compare/store, so it could move the counter backwards and hand out indices twice. It is now atomic().fetch_max, which also affects the non-restart path.
  • eps_solved_subproblems is counted only if !open_subproblem (l.1238).
  • tree_nodes: each node of the tree is counted once (a dive node only by the index whose low rd bits are 0). The test invariant is that tree_nodes is identical with and without restarts: php8–10 give 2·n!−1 in 15/15 runs, and enr_small passes 12/12 in both modes.
  • Restart stats: restarts, restart_items_sum/max, restart_s_max, restart_drain_ms_* (flag raised → S1), restart_first/last_sec. The ENR idle time includes the S1→S3 waits.
