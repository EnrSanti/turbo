Names

root = the initial problem (UnifiedData::root, never changes). subroot = the root of the subproblem a block is solving (BlockData::root_store, taken at depth 0 of step F). An item (snap, k, c) = from the subroot of block snap, follow its path to level k and take child c.

Every name introduced by ENR starts with enr_ (variables, fields, functions, printed statistics) or Enr (types: EnrFrontierItem, EnrPhase); macros and constants use ENR_ (ENR_PH, ENR_HIST, ENR_TL, ENR_MAX_WAITS). Exceptions, on purpose: the command-line flags stay -restart and -restart_each_block (job scripts use them), the timer Timer::BACKTRACK_ENR, and the short locals that live inside one ENR block (n, s, k, w, pending, keep, last_k, src, grid, ...). Upstream names whose meaning changed keep their name (num_subproblems, now __shared__).

Name clash handled: before 2026-11-11 the printed enr_restart_* statistics (section 7b of stats_explained.txt) meant one backtrack (restore + its fixpoint). Now enr_restart_* means only the load-balancing restart; the backtrack function is enr_record_backtrack (was enr_record_restart); its fields keep the short prefix enr_rs_*. No current identifier collides. compare_restart_stats.py and analyze_mznc_results.py map the new printed names to the old keys, so logs from before (e.g. the MZN 2024 series) and after are read the same way. The rename changes no machine code: the GPU SASS of the rebuilt binary is identical to the previous one (build/gpu-release/turbo.before_rename), the solve kernel still uses 98 registers, and benchmarks/enr_small passes 12/12.

3. ENR CODE — heap sizing (barebones:732-738, configure_gpu_barebones)

//ENR CODE -- begin: heap sized from the free memory (upstream: share of the total memory).
size_t free_mem, total_mem;

Upstream reserves 97% of totalGlobalMem; when part of the GPU is taken (display), nothing is left for the per-launch local memory (stack) and every launch fails. 4. ENR CODE — meet race fix in the E-skip (barebones:1035-1040)

size_t next_subproblem_idx = ((block_data.subproblem_idx >> remaining_depth) + size_t{1}) << remaining_depth;
//ENR CODE -- begin (bug fix): `meet` is load/compare/store, not an atomic max ...
// while(grid_data->next_subproblem.meet(ZLB<size_t, bt::local_memory>(next_subproblem_idx))) {}
grid_data->next_subproblem.atomic().fetch_max(next_subproblem_idx, cuda::memory_order_relaxed);
//ENR CODE -- end

Context (upstream step E): a dive that fails at depth d < subproblems_power proves the whole subtree of 2remaining_depth indices empty, so the counter is pushed to the first index after it. ZLB::meet on atomic_memory_grid is a load, a compare and a store; between them other blocks can atomic()++ the counter past next_subproblem_idx, and the store then moves it back: indices are handed out twice (duplicated work, and double-counted eps_solved_subproblems). fetch_max is one atomic RMW, monotone. Found while verifying enr_tree_nodes (§11): duplicates showed up as enr_tree_nodes > 2·n!−1 on pigeonhole.

6. ENR CODE — restart: data structures

6.1 EnrFrontierItem (barebones:99-103) — one open node, 8 bytes

struct EnrFrontierItem {
  int snap;              // block whose snapshot holds the path (blockIdx of the block that left the node)
  unsigned int k : 31;   // level in that path
  unsigned int c : 1;    // child of decision k: 0 = children[0] (left), 1 = children[1] (right)
};

The open node is: snapshot root store of block snap, then the decisions enr_snap_dec[0..k) with their current child, then child c of decision k. This is the same representation the upstream backtrack uses (root store + re-apply path), so the rebuild (§8.3) is the backtrack code with a different source. enr_restart_now_ns() (:90-93, STATS: only used for the restart times) = system_clock (globaltimer) in ns, same clock on all SMs.

7.1 Memory estimate (barebones:719-721)

mem_per_block += store_bytes + sizeof(LightBranch)·MAX_SEARCH_DEPTH + sizeof(EnrFrontierItem)·1024 (snapshot store, snapshot stack, item quota). This reduces num_blocks through the upstream mem_for_blocks / mem_per_block rule if memory is tight.

7.2 Cooperative-launch check (barebones:766-785)

8. ENR CODE — restart: the kernel, step by step

Upstream structure of gpu_barebones_solve: A (allocate) → B loop while(idx < num_subproblems && !stop) { C copy global root → D dive subproblems_power levels following the bits of idx → E skip if the dive failed | F DFS of the subproblem (I bound, II propagate, III split, IV backtrack) → G idx = next_subproblem++ } → end (stats, best solution). The restart wraps B..G in a round loop and changes C, D and the end of F.

8.1 Round-loop head (barebones:877-893)

Thread 0 initialises the shared variables (enr_s_bits = subproblems_power, num_subproblems = eps_num_subproblems); block 0 records enr_kernel_start_ns (STATS). enr_round = 0; while(true) { encloses the upstream subproblem loop. The subproblem loop condition stays idx < num_subproblems && !stop (no !enr_restart): the flag is only raised when blocks are idle, which happens only when the counter is exhausted, so any block that reaches G after the flag gets an index ≥ num_subproblems and leaves.

8.2 Step C (barebones:911-914)

Round 0: upstream copy of the global root (unified_data->root.store->copy_to). Later rounds: C'.

8.3 Step C' — rebuild an item (barebones:915-948)

enr_cur_item = enr_items[subproblem_idx >> enr_s_bits];                 // thread 0, then __syncthreads
const BlockData& src = blocks[enr_cur_item.snap];
src.enr_snap_store->copy_to(group, *block_data.store);          // root store of the source block
while(has_changed) {                                         // block-parallel re-embed, until stable
  for(i = threadIdx.x; i < k; i += blockDim.x)
    has_changed |= store->embed(src.enr_snap_dec[i].var, src.enr_snap_dec[i].current());
}
store->embed(src.enr_snap_dec[k].var, src.enr_snap_dec[k].children[c]);   // thread 0
current_strategy = src.enr_snap_root_strategy;                          // next_unassigned_var stays 0 (step C)

This is a copy of the upstream backtrack (step IV, :1146-1175) where decisions, root_store (the subroot), snapshot_root_strategy are those of the source block, and the last level takes child c instead of next(). No propagation here: the rebuilt node is propagated by the first dive propagate() (D) or, if s = 0, by the first F iteration. depth is reset to 0 (upstream line before C): the rebuilt node becomes the root of a new subproblem, its own root_store is taken at F-III depth 0 as upstream does.

8.4 Step D — dive (barebones:958)

remaining_depth = enr_s_bits (was config.subproblems_power). The dive follows the low s bits of idx below the rebuilt node, exactly as upstream follows the bits below the global root. Step E (skip of a failed dive) is unchanged except for the race fix (§4); it is offset-relative: ((idx >> d) + 1) << d with d ≤ s stays inside the same item because indices of one item are aligned on 2s.

8.5 End of the F body: stop on restart (barebones:1190-1200)

if(enr_restart) { if(threadIdx.x == 0) enr_open_subproblem = !stop; __syncthreads(); break; }

Placed at the end of the while(!stop) body, after III (split + embed of the left decision) or IV (backtrack: restore + embed of the right decision). So: root_store already exists (taken at depth 0 in III), the current node is embedded but not propagated ⇒ it is unexplored and becomes an item; nothing is lost and nothing is explored twice. The two upstream breaks inside IV (leaf at depth 0, rope = −1) are before this check: if the subproblem is finished, enr_open_subproblem stays false. enr_open_subproblem = !stop: if the timeout hit at the same time, nothing is harvested.

Solved-subproblem guard (:1203): && !enr_open_subproblem so an interrupted subproblem is not counted in eps_solved_subproblems.

8.6 End of a round (barebones:1224-1384)

Off-path (:1226-1228): if(!enr_restart_enabled) break; — uniform, the kernel ends exactly as upstream.

Before S1 (:1231-1245): thread 0: a block that left the loop without stop and without enr_restart ran out of indices ⇒ idle = enr_idle_blocks.fetch_add(1) + 1; if idle == enr_restart_threshold this block raises the flag (enr_restart_flag.store(1)). fetch_add returns a different value to every caller, so exactly one block raises it. (STATS: phase charge, enr_wait_begin.)

S1 grid.sync() (:1247), then ++enr_round. Idle blocks wait here until every busy block has seen the flag and finished its current node.

Harvest (:1250-1304, only if enr_open_subproblem):

  1. enr_snap_dec.resize(decisions.size()) if decisions grew (push_decision doubles it). Device malloc inside the kernel.
  2. Copy root_store → enr_snap_store (block-parallel) and decisions[0..depth) → enr_snap_dec field by field (var, children[0..1], current_idx; not the ropes).
  3. Thread 0: enr_snap_root_strategy.
  4. Open nodes (if depth ≥ 1): one item (k, 1) for every level k < depth with current_idx == 0 (right branch never started), plus the current node (depth−1, decisions[depth−1].current_idx). After a split the current node is (depth−1, 0) and level depth−1 also yields (depth−1, 1); after a backtrack it is (depth−1, 1).
  5. Quota (:1278-1287): if pending + 1 > enr_items_per_block (1024): keep the 1023 shallowest pending right branches, and replace everything deeper by the left child of the last kept level (last_k): complete but re-explores refuted parts. enr_st_truncated++ (STATS). Observed in the MeluXina MZN 2024 series: 2 blocks in network_50_cstr/toy_network_1000_m (job 5476403) and 1 block in graph-clear/planar_n20_seed2022_15 (job 5477197), both with -restart 10 and 216 blocks.
  6. Reserve m = keep + 1 slots with one enr_n_items[enr_round&1].fetch_add(m), write the items in order of increasing k (shallow first), the current node last.

reset_round (:1306-1332, block 0 thread 0, in parallel with the harvests):

  1. exact best bound: appx_best_bound.meet(blocks[b].best_bound) for all b (all blocks are stopped, so the minimum is exact; repairs the lost-update race of the racy meet in propagate).
  2. enr_host_stop = unified_data->stop.test(), read once so every block takes the same decision after S3. (STATS: drain time = now − enr_raise_ns if the flag is up.)
  3. next_subproblem = B (a plain store: blocks 0..B−1 start on their own index).
  4. –5. enr_idle_blocks = 0, enr_restart_flag = 0.
  5. enr_n_items[(enr_round+1)&1] = 0: the counter of the next restart (the current one is being filled now and read after S3).

S3 grid.sync() (:1334). (There is no S2: dropped in design rev. 3; it would only be needed for sorting items or per-item split depth.)

Plan the next round (:1336-1381): every block reads n = enr_n_items[enr_round&1]; finished = enr_host_stop || n == 0 (uniform). If not finished, thread 0: smallest s with n·2s ≥ T (capped at 40), enr_s_bits = s, num_subproblems = n<<s, clears enr_restart/enr_open_subproblem, subproblem_idx = blockIdx.x; block 0 updates the STATS (enr_st_restarts, enr_st_items_*, ...). Then __syncthreads(); if(finished) break; and the round loop restarts at the subproblem loop.

Termination: a round with n = 0 means no block had an open subproblem, i.e. every block finished all its work ⇒ the search is complete. All blocks leave the round loop at the same barrier, so num_blocks_done etc. at :1386- run as upstream.

9. ENR CODE — trigger: raise (idle block) and poll (propagate())

Raise (end of a round, before S1, :1232-1241):

if(!stop && !enr_restart) {                                  // this block is idle
  int idle = grid_data->enr_idle_blocks.fetch_add(1) + 1;
  if(idle == grid_data->enr_restart_threshold) {             // 1 with -restart_each_block
    grid_data->enr_restart_flag.store(1);
    grid_data->enr_raise_ns = enr_restart_now_ns();          // STATS
  }
}

Poll: propagate() gets bool& enr_restart (:567-568, :1427-1428; calls :976, :1087). Inside the thread-0 block after the node counters:

// node limit (-cutnodes): with restarts every block must leave the round loop together   (:1566-1567)
if(nodes >= stop_after_n_nodes || stop.test()) { ...; stop = true;
  if(grid_data.enr_restart_enabled) unified_data.stop.test_and_set(); }
// poll                                                                                   (:1570-1574)
if(enr_restart_enabled && !enr_restart && enr_restart_flag.load() != 0) enr_restart = true;

Before the simplification the flag was raised by a busy block inside propagate() (CAS 0→1 after checking the idle count, the round age for -restart_min_ms and the restart count for -restart_max), because an idle block waiting at S1 cannot re-check a time condition later. Without these two options the condition is only "the idle count reaches the threshold", which is known exactly at the moment an idle block increments it, so the idle block raises the flag itself. Cost per node: one relaxed load. A dive node also polls; the dive continues to its end and the stop happens at the end of the first F iteration (or the block leaves at G if the dive failed). If every block is idle (no busy block left), the flag is raised but n = 0 after S3 and the kernel ends.

Why test_and_set on the node limit: without it, the block that hits -n would go to S1 while the others keep searching until the counter is empty; upstream's per-block stop has no meaning when all blocks must meet at the barrier.

10. Correctness arguments to check

  • Frontier partition (RESTART_GRIDSYNC.pdf rev. 5, Prop. 1, ~ Lecoutre nld-nogoods): the unexplored part of a DFS stopped at a node = the right siblings never started along the path (current_idx == 0) + the current unpropagated node. Ropes do not add levels: a level with current_idx == 1 is in its right branch, nothing pending there; levels deeper than depth are dead after a backtrack.
  • Dyadic alignment (Prop. 2): item j owns indices [j·2s, (j+1)·2s); D and E work on the low bits, so a skip never crosses into another item.
  • One-writer rule between S1 and S3: harvest writes own enr_snap_*, own enr_items range, enr_n_items[r&1] (atomic); reset_round writes the other shared fields and enr_n_items[(r+1)&1]; nobody reads what another writes before S3. Snapshots are read-only during the round they serve; the next harvest overwrites them only after S1, when nobody rebuilds.
  • Single snapshot buffer suffices: rebuild (C') is not interruptible (the flag is tested only at the end of F's body), so no block reads snapshot r while snapshot r+1 is written.
  • Bound: the exact meet in reset_round makes appx_best_bound exact at every round start.
  • Verified after removing the ropes copy and enr_snap_root_next_unassigned_var (2026-11-23): php8/9/10 enr_tree_nodes again 80639 / 725759 / 7257599 in the three modes, all UNSAT; enr_small 12/12; 98 registers.
  • Verified after the simplification (2026-11-23, RTX 4050, 40 blocks): php8/9/10 (UNSAT, generated FlatZinc, input order) enr_tree_nodes = 80639 / 725759 / 7257599 = 2·n!−1 with no restart, -restart 10 and -restart_each_block; php10 7.66 s → 2.25 s (-restart 10) / 2.27 s (-restart_each_block), 7 restarts, idle 71.9 % → 0.1 %; benchmarks/enr_small 12/12; solve kernel 98 registers. Verified before (11-17/18): php8/9/10 (UNSAT) enr_tree_nodes = 2·n!−1 identical with/without restarts (15/15 runs); benchmarks/enr_small 12/12 both modes; php10 7.7 s → 2.4 s, golomb10 13.9 s → 5.9 s (-restart 3..10 -restart_min_ms 0). Kernel 98 registers, no spills (at implementation time).

11. ENR STATS — restart statistics

11.1 enr_tree_nodes / enr_tree_failures

Goal: count each node of the search tree once, whatever the decomposition, so runs with and without restarts are comparable (nodes counts dive nodes repeatedly: every index re-dives the shared prefix).

  • Dive: before each dive propagate (:974-975) enr_in_tree = (idx & (2remaining_depth−1)) == 0: the node at that depth is shared by all indices with the same high bits; only the smallest (low bits 0) counts it.
  • DFS (F): enr_in_tree = true (:1057): every DFS node is visited once.
  • propagate (:1553-1556): if enr_in_tree, enr_tree_nodes++, enr_tree_fails += is_bot.
  • Summed in Statistics::meet (statistics.hpp:328); printed by print_enr_restart_statistics (:495-515) as enr_tree_nodes, enr_tree_failures, enr_redundant_dive_nodes = nodes − enr_tree_nodes (printed whenever enr_tree_nodes > 0, also without -restart).

Why it is exact for satisfaction/UNSAT: the counter is monotone (after the fetch_max fix), so among indices sharing a dive prefix the one with low bits 0 is always handed out first, and with deterministic propagation it reaches every shared node the others reach. With optimisation, propagation of a dive node depends on appx_best_bound at that moment: the low-bits-0 index can fail at a shallower node (stronger bound) while another index of the same prefix, which propagated earlier with a weaker bound, went deeper; those deeper nodes are then counted by nobody, and enr_tree_nodes is slightly low. Verified exact on php (UNSAT); treat it as approximate on optimisation instances.

11.3 Barrier waits as idle time

Each block records [S1 arrival, S3 exit) (:1244, :1339-1347), up to 256 intervals (+ total enr_wait_ns). reduce_blocks adds enr_wait_ns to enr_idle_ns_sum (:1621) and, for the 20-slice timeline, adds the overlap of each wait with the slice to idle and does not count a block waiting at the slice end as busy (:1643-1655). After S3, enr_ph_t and block_data.timer are set to now so the wait is not charged to any phase or upstream timer; enr_after_restore = false since an interrupted backtrack has no following fixpoint.

With restarts every block lives until the kernel end, so upstream's first_block_idle_time (= block lifetime) no longer measures idleness; use enr_pct_idle / the timeline, which include the barrier waits.

15. How to remove the stats / turn the restart off

  • Restart off: run without -restart (default). Code path = upstream + §3 + §4.
  • Remove ENR STATS: delete every line ending in //ENR STATS... and every //ENR STATS -- begin … -- end block. No line mixes CODE and STATS. The propagate() call sites stay (their tag is CODE), TIMEPOINT(BACKTRACK_ENR) goes with Timer::BACKTRACK_ENR, and in common_solving.hpp:648 restore return iprop->deduce(i);. The local lala-core is optional (-DLOCAL_LALA_CORE=OFF) once enr_* getters are no longer used.
  • Remove ENR CODE (back to upstream): revert the restart, the fetch_max (keep it, it is a fix) and the heap line.
